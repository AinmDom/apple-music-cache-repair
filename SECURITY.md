# Security

This utility removes a narrowly scoped cache file and can optionally close the
registered Apple Music application. Unexpected link traversal, deletion outside the
intended cache, task ownership bypasses, and unsafe update/rollback behavior are
security-sensitive issues.

When this repository is published, maintainers should enable GitHub private
vulnerability reporting. Use the repository Security tab's private reporting option
when available. Do not publish exploit details or personal machine data in a public
issue. If private reporting is unavailable, first open a minimal issue asking the
maintainer for a private contact, without vulnerability details.

The project currently has no code signing certificate or automated updater. Review
source and verify release checksums. Never disable system security controls to run it.
